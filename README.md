# GRAIL-Gesture-Responsive-Arm-for-Intuitive-Linkage
Robotic hand which mimics hand gestures. 

This repo contains the python script to run the arm with mediapipe (hand_control.py) with esp32 sketch to recive data through uart and drive pwm signals through servos.

This repo also contains a custom model for gestures.

Everything is explained in report (Group3_GRAIL.pdf).
